## Product constraints

- No public registration.
- Admin creates users.
- Multiple admins supported.
- At least one active admin must always exist.
- Admin cannot read chat contents unless they are a conversation participant.
- No task stopwatch or time tracking.
- No attendance.
- No marks, GPA, CGPA, or grade tracking.
- No Google Calendar integration.
- No application file uploads.
- External URLs are allowed.
- English only for V1.
- Application timezone is Asia/Kolkata.
- ₹0 infrastructure target.
- Supabase free tier.
- Cloudflare Pages.
- GitHub private repository.
- No service-role key in browser code.
- PostgreSQL RLS is the final authorization boundary.
